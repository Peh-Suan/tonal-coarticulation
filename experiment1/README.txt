To implement the data processing, run `data_processing.py`.

The following packages are required:
```
pandas
tgt
praat-parselmouth
numpy
tqdm
```

Run `pip install <PACKAGE_NAME>` in command line to install the package.

To conduct the data analysis, run `data_analysis.R`.
